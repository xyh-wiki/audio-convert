# 功能说明

版本：1.4（对应当前工作区代码）
读者：产品、前端开发与测试人员

## 目标与边界

该应用在用户的浏览器中使用 FFmpeg.wasm 完成音频转换、视频转换和视频音频提取。媒体文件不上传到应用服务器，也不需要账号。

范围内：批量选择或拖放媒体文件、格式和预设选择、输出命名、音频/视频参数、裁剪、音量、响度标准化、旋转、镜像、GIF 输出、串行队列、进度、取消、重试、单个或批量下载，以及完整视口的三栏转换工作区。范围外：云端存储、账户、后台处理、DRM 绕过、服务端打包 ZIP、保证所有编解码器在所有浏览器可用。

页面还提供一个可选的文档问答助手，用于回答功能、格式支持和本地处理边界；它不读取、上传或处理用户选择的媒体文件，也不替代转换错误提示。

## 使用规则

1. 单次队列最多 20 个文件，单文件最大 2 GB；空文件和不在支持列表中的媒体文件会被拒绝并说明原因。
2. 系统依据 MIME 类型或文件扩展名判断音频/视频模式；用户可在未入队处理前修改模式和输出格式。
3. 队列始终串行执行。只有空闲、失败或已取消的任务可开始；完成任务不可重复入队，失败或取消任务可重试。
4. 取消只作用于正在执行的任务。清空队列会保留正在处理的任务，避免把运行状态伪装成已删除。
5. 成功结果只保存在当前页面的 Blob URL 中；移除任务、清空、重试或离开页面时会释放该 URL。刷新或关闭页面会丢失队列和下载结果。
6. 用户从队列选择单个文件后才编辑其转换类型、输出格式、预设和高级参数。排队或处理中的任务锁定参数，防止执行中的命令与界面显示不一致。
7. 批量预设仅更新未开始、失败或已取消的任务；“下载全部”仅下载已完成的结果；“清除完成项”不影响其他队列状态。
8. 任务可在未开始、失败或取消状态下调整顺序；排队和处理中任务不可调整，避免正在执行的顺序与界面不一致。
9. 输出文件名使用用户输入的基础名称和目标扩展名，并替换不适用于文件名的字符。批量命名会重设可编辑任务为“原始基础名 + 后缀”。
10. 开始前会提示大文件、低内存设备、同格式输出和 GIF 体积风险；起始时间不小于结束时间属于阻断错误。失败提示给出降低质量、缩短片段或改用 MP4/MP3 的下一步，不显示内部堆栈。
11. 默认预设和命名后缀只保存在当前浏览器的 `localStorage`；媒体、任务队列和结果不持久化。

## 用户可见状态

`idle → queued → processing → completed`；处理阶段可转为 `canceled`，错误转为 `error`。`error` 和 `canceled` 可以重试并回到 `queued`。每个错误状态必须呈现可行动的提示，不暴露内部堆栈。

## 公开发现与收录

首页是唯一公开、可收录页面。构建期会预渲染工作区标题、功能说明、格式支持和本地处理边界；搜索引擎无需执行 JavaScript 即可读取核心内容。`robots.txt` 允许抓取并声明 sitemap，sitemap 仅包含 canonical 首页。队列文件名、转换进度和下载 URL 仅存在于浏览器运行时，不进入静态页面或 sitemap。助手通过同域 `/assistant/*` 动态加载，不构成可索引正文；其 API 不应加入 sitemap 或搜索内容。

## 验收要点

- 受支持文件可加入队列，拒绝项不进入队列。
- “转换全部”按顺序处理可启动任务，已经完成的任务不再次处理。
- 取消后任务显示已取消状态，不会随后显示为失败或完成。
- 结果下载名称使用原文件名和目标扩展名；移除后不保留浏览器内存引用。
- 支持拖放、文件选择和 `Ctrl/⌘ + O`；在窄屏下队列、编辑器和批次操作按顺序垂直排列，主要转换动作仍可访问。
- 可编辑输出基础名称、裁剪区间、响度标准化、旋转与镜像；GIF 任务不保留音频。
- 无效剪辑区间不可启动；大文件等非阻断提示仍允许用户自主开始。
